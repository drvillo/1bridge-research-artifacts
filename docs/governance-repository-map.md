It is an implementation index, not a research result or a claim of deployment, independent review, or complete D1–D4 delivery. The four manuscript tracks have distinct purposes: the encryption-system description explains primitives and confidentiality boundaries; the system companion follows product workflows and trust boundaries; the protocol description specifies signed artifacts and adversarial states; and the benchmark report measures the actual implementations with pinned versions and raw observations. Their canonical `.tex` sources currently live in the private application repository's `research/` directory. This public repository holds reproduction artifacts and may receive reviewed manuscript sources later; a linked implementation commit alone does not convert an older measurement into a new result.

For the new governance work, record at least these separate evidence classes before making manuscript claims: portable-library vectors/tests, observer persistence and catch-up tests, integrated application route/transaction tests, end-to-end observer outage and suppressed-receipt cases, production deployment observations, and reproducible performance samples. Preserve negative cases: source-only polling cannot reveal a coherent branch hidden from every independent participant, a pending or unmatched receipt alone is not proof of operator tampering, and observer availability must never gate a 1Bridge release under the selected strict-auditing policy.
